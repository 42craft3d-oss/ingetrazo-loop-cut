# Loop Cut v1.0

Primera publicación independiente de Loop Cut para IngeTrazo.

- Inserta un anillo de aristas en una banda cerrada de cuadriláteros.
- Intenta una sección plana en piezas compatibles con triángulos u otros polígonos.
- Muestra el recorrido en rosa antes de confirmar.
- Rechaza recorridos abiertos, con agujeros o ambiguos antes de alterar la malla.
- Conserva los atributos de las caras y permite deshacer el corte con Ctrl+Z.
- Añade un botón propio en la barra LoopTools.

Instalación: descarga `loop_cut.py`, cópialo en la carpeta que abre **Extensiones → Abrir carpeta de plugins** y reinicia IngeTrazo. Consulta el README para imágenes, uso y límites.

## English

Initial standalone release. Adds a previewed edge ring through a closed quad strip or a suitable planar cross-section. Rejects open and ambiguous paths and supports one-step undo.
